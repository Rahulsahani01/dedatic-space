## Getting Started

- Node.js: Version 14 or higher

## Installation :

1. Clone the repository:

```sh
git clone
```

2. Navigate into the project directory:

```sh
cd dedactic-space
```

3. Install dependencies:

```sh
npm install
```

6. Start the server:

```sh
npm run dev
```
